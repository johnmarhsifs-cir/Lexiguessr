## Description

Lexiguessr is a minimalist web-based word-guessing game that uses live dictionary and thesaurus data to provide progressive hints while players deduce a hidden word.

## Deployed Website Link

https://johnmarhsifs-cir.github.io/Lexiguessr/

## How to Access & Use

1. Visit https://johnmarhsifs-cir.github.io/Lexiguessr/ in your browser (or clone the repository and open `index.html`).
2. Select a difficulty level (`Easy` to `Extremely Hard`, ranging from 5 to 12 letters).
3. Type a single letter or the full word into the input box and click **Guess**.
4. Click **Hint** to unlock up to 10 progressive clues (each extra hint reduces the points earned for that word).
5. Solve words before running out of your **6 lives** to build your score and streak.

## APIs Used

- **Random Word API** (`https://random-word-api.herokuapp.com`) – Generates random target words by length and difficulty.
- **Merriam-Webster Collegiate Dictionary API** (`https://dictionaryapi.com`) – Provides definitions, part of speech, and syllable data.
- **Merriam-Webster Collegiate Thesaurus API** (`https://dictionaryapi.com`) – Provides synonyms and antonyms.
