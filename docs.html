Project Overview

Lexiguessr is a web-based word-guessing game that gives players dictionary and thesaurus hints to help them guess a hidden word while improving their vocabulary.

Objectives

  • Build a simple word-guessing game using HTML, CSS, and JavaScript.
  • Fetch random words, definitions, and synonyms using public APIs.
  • Provide a clean user interface with Light and Dark modes.

Target Users

  • Students and language learners practicing vocabulary.
  • Casual players who enjoy word puzzle games.

Features

  • 5 Difficulty Levels: 5 to 12 letter words.
  • 10 Progressive Hints: Definitions, grammar, and letter clues.
  • Game Stats: Tracks score, streak, and 6 lives.
  • Theme Toggle: Switches between Light and Dark mode.

Technologies Used

  • HTML, CSS, JavaScript
  • APIs: Random Word API, Merriam-Webster Dictionary & Thesaurus APIs
  • Deployment: GitHub Pages

API Integration

  • Random Word API: Retrieves 5 random words based on selected difficulty and word length.
  • Merriam-Webster Collegiate & Thesaurus APIs: Retrieves the word's definition, part of speech, syllables, synonyms, and antonyms to build the game hints.

Problems Encountered and Solutions

Problem: We had a hard time finding and navigating the output of the Thesaurus and Collegiate Dictionary APIs because the JSON data was very large. We also had difficulty deciding what to include as hints.
Solution: We studied the API structure, selected simple and clear hints, and stored them in an array that matched the structure of the API output.

Conclusion

Our pair successfully created Lexiguessr, a web-based word-guessing game that integrates multiple APIs to turn dictionary and thesaurus data into interactive game hints.
